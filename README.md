# JP SteakHouse Salvador

Site institucional e moderno desenvolvido para a churrascaria premium **JP SteakHouse Salvador**, localizada em Pituaçu.

## 🚀 Tecnologias

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Lucide React** (Ícones)

## 🥩 Funcionalidades

- **Experiência Visual Imersiva**: Vídeo de abertura na brasa e galeria de fotos do ambiente e cortes.
- **Cardápio Interativo**: Navegação por categorias (Cortes Nobres, Drinks, Cervejas e Sobremesas).
- **Painel de Reservas**: Informações completas sobre horários, valores do rodízio, link direto para reserva online e WhatsApp.
- **Responsividade Total**: Layout adaptável para smartphones, tablets e desktops.

## 🛠️ Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/RayanSantsz/jpstakehouse.git
   cd jpstakehouse
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Build para produção:**
   ```bash
   npm run build
   ```
